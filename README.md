# لندیکسا — قالب HTML لندینگ معرفی اپلیکیشن

قالب HTML راست‌چین برای معرفی و دانلود اپلیکیشن موبایل — بدون هیچ وابستگی خارجی، سریع و ریسپانسیو؛ به‌همراه صفحه‌های وبلاگ و نسخهٔ انگلیسی (چپ‌چین).

## ساختار فایل‌ها

```
landixa/
├── index.html              صفحه اصلی — نسخهٔ تیره (فارسی، RTL)
├── home-light.html         همان صفحه — نسخهٔ روشن
├── home-warm.html          همان صفحه — نسخهٔ گرم
├── blog/
│   ├── index.html          وبلاگ — فهرست ۶ پست نمونه (تاریخ شمسی)
│   └── post.html           صفحهٔ تک‌پست وبلاگ
├── ltr/
│   └── index.html          دوقلوی انگلیسی (LTR) صفحهٔ اصلی — با dir="ltr"
├── assets/
│   ├── css/style.css       تمام استایل‌ها (توکن‌دار و بخش‌بندی‌شده)
│   ├── js/main.js          تعامل‌ها (منو، لایت‌باکس، FAQ، ریویل)
│   ├── img/                (اختیاری) اسکرین‌شات‌های واقعی اپ خودتان
│   └── fonts/              وزیرمتن (لوکال — بدون CDN)
├── docs/screens/           راهنمای گذاشتن اسکرین‌شات واقعی
└── README.md
```

## نصب

1. پوشه را روی هر هاستی (سی‌پنل، دایرکت‌ادمین، GitHub Pages و…) آپلود کنید.
2. همین‌قدر! هیچ بیلد و وابستگی‌ای وجود ندارد — `index.html` را باز کنید.

## شخصی‌سازی

### تغییر نام اپ و متن‌ها
همهٔ متن‌ها مستقیماً داخل `index.html` هستند. کافیست «کیف من» را با نام اپ خودتان عوض کنید.

### تغییر رنگ‌های قالب
ابتدای `assets/css/style.css` بخش `:root` توکن‌های رنگ است:

```css
--accent:   #22D3EE;   /* رنگ اصلی */
--accent-2: #8B5CF6;   /* رنگ دوم گرادیانت */
--bg:       #0B0F17;   /* پس‌زمینه */
--card:     #131A26;   /* کارت‌ها */
```

فقط همین ۴ مقدار را عوض کنید؛ کل قالب (دکمه‌ها، گرادیانت‌ها، سایه‌ها و
هاله‌ها و نمودار) هماهنگ تغییر می‌کند — رنگ‌های مشتق با `color-mix` خودشان
از همین مقادیر محاسبه می‌شوند.

### نسخه‌های رنگی
سه نسخه از همین صفحه با یک استایل‌شیت مشترک:

| نسخه | فایل | صفت روی `<html>` | حال‌وهوا |
|---|---|---|---|
| تیره (پیش‌فرض) | `index.html` | — | گرادیانت فیروزه‌ای/بنفش روی پس‌زمینهٔ تیره |
| روشن | `home-light.html` | `data-theme="light"` | مینیمال و روشن با آکانت تیل/بنفش |
| گرم | `home-warm.html` | `data-theme="warm"` | همان تیره با آکانت نارنجی/رز |

هر سه فایل فقط یک خط با هم فرق دارند (صفت `data-theme`)؛ استایل و
اسکریپت مشترک است و هیچ CSS جداگانه‌ای وجود ندارد. برای انتشار، فایلی
که می‌خواهید صفحهٔ اصلی باشد را آپلود کنید (می‌توانید هر سه را در دسترس
بگذارید و نسخه‌ها را معرفی کنید).

برای تغییر رنگِ نسخهٔ روشن یا گرم، توکن‌های همان نسخه را داخل بلاک
`html[data-theme="light"]` یا `html[data-theme="warm"]` در ابتدای
`style.css` عوض کنید؛ رنگ‌های سایه، هاله و گرادیانت آن نسخه خودشان از
`--accent` و `--accent-2`‌اش محاسبه می‌شوند.

### تغییر آمار و نظرات
- آمار هیرو: بلوک `hero-stats` در `index.html`
- نظرات: سه کارت `review-card` — متن، اسم و شهر را جایگزین کنید.
- دکمه‌های استور: `href` دکمه‌های کافه‌بازار/مایکت/دانلود مستقیم را لینک اپ خودتان کنید.
  تا وقتی `href="#"` باشد، کلیک روی دکمه پیام راهنما نشان می‌دهد؛ متن این پیام را
  می‌توانید با صفت `data-toast="متن دلخواه"` روی خود دکمه عوض کنید.

### افزودن اسکرین‌شات واقعی
هر `figure.shot` یک اسکرین است. برای تصویر واقعی، داخل `shot-screen` به‌جای خطوط placeholder یک `<img>` بگذارید:

```html
<div class="shot-screen"><img src="assets/img/screen-1.png" alt="داشبورد"></div>
```

راهنمای کامل (محل قرار گرفتن فایل‌ها، ابعاد پیشنهادی، لایت‌باکس و
دسترسی‌پذیری): `docs/screens/README.md`

## نکات فنی

- **RTL استاندارد:** همهٔ فاصله‌ها با خواص منطقی (`inline-start/end`) — با تغییر `dir` به `ltr` قالب خودش قرینه می‌شود.
- **اعداد لاتین:** اعداد داخل `<bdi class="en">` هستند تا در متن فارسی قاطی نشوند.
- **دسترسی‌پذیری:** ناوبری کیبورد، `aria-label`ها، `prefers-reduced-motion`.
- **بدون تصویر:** تمام گرافیک‌ها SVG/CSS هستند — سرعت لود بالا و هیچ درخواست خارجی.
- مرورگرهای پشتیبانی‌شده: کروم/اج/فایرفاکس/سافاری دو سال اخیر.
