# اسکرین‌شات‌های واقعی اپ شما

این پوشه فقط یک یادداشت راهنماست. اسکرین‌شات‌های واقعی اپ خودتان را در
پوشهٔ `assets/img/` (کنار `index.html`) بگذارید و بلوک‌های placeholder را
با تصویر جایگزین کنید.

## ساختار پیشنهادی

```
landixa/
├── index.html
└── assets/
    ├── css/style.css
    ├── img/                  ← تصاویر خودتان اینجا قرار بگیرند
    │   ├── screen-1.png
    │   ├── screen-2.png
    │   └── screen-3.png
    ├── js/main.js
    └── fonts/
```

## مراحل جایگزینی

هر `figure.shot` در بخش «اسکرین‌شات‌ها» یک قاب است. محتوای داخل
`.shot-screen` (خط‌های placeholder) را حذف و یک `<img>` بگذارید:

```html
<figure class="shot" data-shot tabindex="0" role="button" aria-label="بزرگ‌نمایی: داشبورد اصلی">
  <div class="shot-screen">
    <img src="assets/img/screen-1.png" alt="داشبورد اصلی">
  </div>
  <figcaption class="shot-caption">داشبورد اصلی</figcaption>
</figure>
```

## نکات فنی

- **نسبت قاب:** قاب‌ها نسبت `9:17` دارند و تصویر با `object-fit:cover`
  کامل قاب را می‌پوشاند؛ اگر تصویر شما `9:16` باشد، فقط دو طرف آن
  بریده می‌شود.
- **ابعاد پیشنهادی:** حداقل `1080×1920` پیکسل (PNG یا JPG)، هر تصویر
  حداکثر حدود `300KB` تا سرعت صفحه حفظ شود.
- **منبع تصویر:** از اسکرین‌شات واقعی اپ بگیرید (دستگاه یا امولاتور
  اندروید). قاب، سایه و «نوار وضعیت» اپ را همان‌طور که هست ثبت کنید.
- **لایت‌باکس را سالم نگه دارید:** ویژگی `data-shot` روی `figure` و
  متن `figcaption` را تغییر ندهید — با کلیک یا دکمهٔ Enter روی قاب،
  تصویر بزرگ نمایش داده می‌شود.
- **متن دگربیننده‌ها:** `aria-label` هر قاب را به شکل «بزرگ‌نمایی: …»
  نگه دارید و داخل آن، همان عنوان `figcaption` را بنویسید.
- **تعداد:** هر چند قاب بخواهید حذف یا اضافه کنید (نوار، اسکرول
  افقی دارد)؛ پیشنهاد ۳ تا ۶ قاب.
