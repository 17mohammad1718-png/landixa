# تغییرات قالب لندیکسا

همهٔ تاریخ‌ها شمسی است و نسخه‌ها از جدید به قدیم مرتب شده‌اند.
این فایل مخصوص خریدار قالب است؛ تاریخ داخلی توسعه در `docs/ROADMAP.md` نگه داشته می‌شود.

## ۱.۲.۰ — ۱۴۰۵/۰۶/۰۴

- افزودن **وبلاگ** به قالب:
  - صفحهٔ فهرست وبلاگ (`blog/index.html`) با ۶ کارت پست نمونه (کاور CSS خالص، دسته، تاریخ شمسی، زمان مطالعه)
  - صفحهٔ تک‌پست (`blog/post.html`) با بردکرامب، متا، متن، نقل‌قول و بخش «پست‌های مرتبط»
- افزودن **نسخهٔ انگلیسی چپ‌چین** صفحهٔ اصلی در `ltr/index.html` — بدون حتی یک خط CSS جدید (قدت خواص منطقی CSS)
- گزینهٔ «وبلاگ» در منوی هر سه نسخهٔ صفحهٔ اصلی
- کارت‌های پست: هاور، فوکوس کیبورد و انیمیشن ظهور هنگام اسکرول (همان الگوی کارت‌های موجود)

## ۱.۱.۰ — ۱۴۰۵/۰۶/۰۴

- سه نسخهٔ رنگی از صفحهٔ اصلی با **یک استایل‌شیت مشترک**:
  - تیره (پیش‌فرض) — `index.html`
  - روشن و مینیمال — `home-light.html`
  - گرم (نارنجی/رز) — `home-warm.html`
- سیستم توکن رنگ با `color-mix`: با تغییر ۴ مقدار در ابتدای `style.css`، دکمه‌ها، گرادیانت‌ها، سایه‌ها و هاله‌ها هماهنگ عوض می‌شوند

## ۱.۰.۰ — ۱۴۰۵/۰۵/۲۸

- انتشار اولیه: صفحهٔ اصلی تیرهٔ راست‌چین با:
  - ماکاپ گوشی با CSS/SVG خالص (نوار وضعیت، ناچ، محتوای درون‌برنامه)
  - بخش امکانات (۶ کارت)، گالری اسکرین‌شات با لایت‌باکس، مراحل کار، نظرات کاربران، سوالات متداول
  - دکمه‌های دانلود: کافه‌بازار / مایکت / دانلود مستقیم (با پیام راهنما تا زمانی که لینک واقعی گذاشته شود)
- فونت وزیرمتن به‌صورت کاملاً لوکال — صفر درخواست خارجی
- ریسپانسیو از ۳۲۰ تا ۱۹۲۰ پیکسل، دسترسی‌پذیر با کیبورد و `prefers-reduced-motion`
