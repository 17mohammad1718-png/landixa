# قالب پاسخ پشتیبانی — لندیکسا

پاسخ‌های آماده برای سوالات رایج خریداران در پنل فروشندهٔ راست‌چین.
هر پاسخ را مستقیماً کپی-پیست کنید؛ نیازی به ویرایش نیست مگر نام خریدار.

---

## ۱. چطور رنگ‌ها رو عوض کنم؟

فقط ۴ خط اول `style.css` رو تغییر بدید:
```css
--accent: #22D3EE;   /* رنگ اصلی */
--accent-2: #8B5CF6; /* رنگ دوم */
```
بقیهٔ رنگ‌ها (سایه، هاله، گرادیانت) خودکار از این دو مشتق می‌شن.

## ۲. نسخهٔ روشن یا گرم رو فعال کنم؟

به‌جای `index.html`، فایل `home-light.html` (روشن) یا `home-warm.html` (گرم) رو به‌عنوان صفحهٔ اصلی استفاده کنید. هر سه نسخه یک استایل‌شیت مشترک دارن.

## ۳. اسکرین‌شات‌های واقعی خودم رو بذارم؟

داخل هر `figure.shot`، محتوای `div.shot-screen` رو با یک `<img>` جایگزین کنید:
```html
<div class="shot-screen"><img src="assets/img/screen-1.png" alt="داشبورد"></div>
```

## ۴. لینک‌های کافه‌بازار/مایکت رو عوض کنم؟

`href="#"` هر دکمهٔ استور رو با لینک واقعی اپ خودتون عوض کنید. تا وقتی `href="#"` باشه، کلیک یه پیام راهنما نشون میده. متن این پیام هم با صفت `data-toast` قابل تغییره.

## ۵. چطور پست وبلاگ اضافه کنم؟

فایل `blog/index.html` رو کپی کنید و کارت‌های پست رو ویرایش کنید. برای پست جدید، `blog/post.html` رو کپی کنید و متن/عنوان/تاریخ رو عوض کنید. لینک‌های «پست‌های مرتبط» رو هم آپدیت کنید.

## ۶. نسخهٔ انگلیسی کجاست؟

فایل `ltr/index.html` نسخهٔ کامل انگلیسی (چپ‌چین) صفحهٔ اصلیه. متن فارسی رو با ترجمهٔ انگلیسی جایگزین کنید — CSS هیچ تغییری نیاز نداره.

## ۷. روی موبایل درست نمایش میده؟

بله، قالب از ۳۲۰ تا ۱۹۲۰ پیکسل تست شده. گرید امکانات ۳→۲→۱ ستون، منوی همبرگری موبایل، و همهٔ انیمیشن‌ها با `prefers-reduced-motion` سازگارن.

## ۸. نیاز به وردپرس یا سرور خاصی داره؟

نه — کافیه فایل‌ها رو روی هاست آپلود کنید یا حتی مستقیم از `file://` باز کنید. هیچ درخواست خارجی، CDN یا وابستگی نداره.

## ۹. فونت فارسی داره؟

بله، فونت وزیرمتن در ۳ وزن (Regular، Medium، Bold) داخل پوشهٔ `assets/fonts/` قرار داره — کاملاً لوکال، بدون نیاز به اینترنت.

## ۱۰. مجوز استفاده چنده؟

خرید یک‌باره، استفادهٔ نامحدود در پروژه‌های شخصی و تجاری خودتون. فروش مجدد قالب یا قرار دادن در مارکت دیگه مجاز نیست.
