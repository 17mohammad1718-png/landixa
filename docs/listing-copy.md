# متن آگهی فروش — لندیکس (قالب HTML لندینگ اپلیکیشن)

کپی آماده برای فرم ارسال قالب در پنل فروشندهٔ راست‌چین. هیچ لینک شخصی
و اطلاعات تماسی ندارد (قانون رد خودکار آگهی) و همهٔ تاریخ‌ها شمسی است.
بخش‌ها دقیقاً مطابق فیلدهای فرم جدا شده‌اند.

---

## عنوان (H1)

**لندیکس | قالب HTML لندینگ معرفی اپلیکیشن — راست‌چین، ۳ نسخهٔ رنگی، وبلاگ و نسخهٔ انگلیسی**

## توضیح کوتاه (۲ تا ۳ خط، برای خلاصهٔ کارت)

لندیکس یک قالب HTML تک‌فایلی‌وار و فوق‌سبک برای معرفی و دانلود اپلیکیشن موبایل است؛ راست‌چین، بدون هیچ وابستگی خارجی، با ماکاپ گوشی CSS خالص، دکمه‌های کافه‌بازار/مایکت/دانلود مستقیم، صفحهٔ وبلاگ کامل و دوقلوی انگلیسی (LTR). فقط فایل‌ها را آپلود کنید — بدون بیلد، بدون وردپرس.

  حرفه‌ای که کاربر را در چند ثانیه به دکمهٔ نصب می‌رساند — چه در کافه‌بازار، چه مایکت،

## لیست امکانات (برای باکس features)

- سه نسخهٔ رنگی (تیره / روشن / گرم) با یک استایل‌شیت مشترک
- صفحهٔ وبلاگ: فهرست ۶ پست + صفحهٔ تک‌پست + پست‌های مرتبط
- نسخهٔ انگلیسی چپ‌چین (LTR) صفحهٔ اصلی
- ماکاپ گوشی CSS/SVG خالص — بدون هیچ عکس و بدون تصاویر هوش‌مصنوعی
- دکمه‌های دانلود: کافه‌بازار، مایکت، دانلود مستقیم APK
- گالری اسکرین‌شات با لایت‌باکس (کیبورد هم کار می‌کند)
- آکاردئون سوالات متداول با باز/بسته‌شدن تک‌آیتم
- انیمیشن ظهور هنگام اسکرول + پشتیبانی prefers-reduced-motion
- فونت وزیرمتن لوکال (۳ وزن) — بدون CDN و فونت خارجی
- توکن‌های رنگ با color-mix: تغییر کل پالت با ۴ مقدار
- خواص منطقی CSS (RTL/LTR)
- ریسپانسیو ۳۲۰ تا ۱۹۲۰ پیکسل
- صفر وابستگی خارجی، صفر فریم‌ورک، صفر بیلد
- تاریخ شمسی در همهٔ بخش‌ها
- کد تمیز و دست‌نویس‌شده با کامنت فارسی/انگلیسی

## سوالات متداول خریداران (FAQ آگهی)

- **برای اجرا به چه چیزی نیاز دارم؟** هیچ چیز خاصی؛ یک هاست ساده یا حتی گیت‌هاب پیجز کافی است. فایل‌ها را آپلود کنید و تمام.
- **وردپرس یا CMS لازم است؟** خیر؛ قالب HTML خالص است و با ویرایش دستی فایل‌ها شخصی‌سازی می‌شود.
- **چطور رنگ قالب را عوض کنم؟** در ابتدای `assets/css/style.css` چهار مقدار `--accent`، `--accent-2`، `--on-accent` و `--bg` را عوض کنید؛ کل قالب هماهنگ تغییر می‌کند.
- **اسکرین‌شات واقعی اپم را چطور بگذارم؟** داخل هر `shot-screen` به‌جای خطوط نمونه یک `<img>` بگذارید؛ راهنمای کامل و ابعاد پیشنهادی داخل بسته (`docs/screens/README.md`) هست.
- **نصب اپ به فروشگاه وصل است؟** دکمه‌های دانلود لینک placeholder دارند؛ فقط href هر دکمه را با لینک اپ خودتان عوض کنید.
- **نسخهٔ انگلیسی چطور کار می‌کند؟** فایل `ltr/index.html` همان صفحهٔ اصلی با `dir="ltr"` و متن انگلیسی است؛ چون CSS از خواص منطقی استفاده می‌کند، همه‌چیز خودش قرینه می‌شود.
